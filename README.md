# Neural Network from Scratch (NumPy)

A 4‑layer neural network built entirely from scratch using NumPy — no PyTorch, no TensorFlow, no Keras. Every forward pass, backward pass, and weight update is implemented manually.

## Architecture

- **Input layer:** 6 features
- **Hidden layer 1:** 10 neurons (ReLU)
- **Hidden layer 2:** 20 neurons (ReLU)
- **Hidden layer 3:** 10 neurons (ReLU)
- **Output layer:** 1 neuron (Linear)
- **Loss:** MSE with L2 regularization

## What Is Implemented

- Forward pass
- Backpropagation (manual chain rule)
- ReLU activation and its derivative
- Linear output activation
- Mean Squared Error loss
- L2 regularization (penalty + gradient)
- Mini‑batch gradient descent
- Train / Dev / Test split
- Feature scaling with StandardScaler

## Why I Built This

To understand deep learning math from the ground up
